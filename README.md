# 📊 Employee & Project Budget Analytics Dashboard

This repository contains a fully interactive **Power BI Dashboard** designed to analyze **employee details, project budgets, organizational departments, and capital distribution**. It integrates HR and project planning insights into a clean, intuitive interface that supports data-driven decision-making across the organization.

---

## 🚀 Project Overview

This dashboard provides a centralized analytical view of:

- **Employee Profiles** (Name, Job Title, Department, Salary, and Headshot)
- **Project Distribution** (Capital allocation across various goals)
- **Departmental Goals & Budget Summary**
- **Project Budget Comparison**
- **Department-wise Budget Breakdown**
- **Status-based Filtering (Upcoming, Completed, Ongoing)**

The dashboard helps businesses understand how capital is allocated, how projects are progressing, and how different departments contribute to organizational objectives.

---

## 📌 Key Features

### 🔹 **Employee Panel**
- Dynamic Employee ID selector  
- Employee image preview (Headshot)  
- Auto-populated personal & job details  

### 🔹 **Project Distribution (Donut Chart)**
- Visual breakdown of capital spent per project goal  
- Total capital overview  

### 🔹 **Departmental Cost Summary**
- Sum of project cost  
- Salary expenditure  
- 2-year budget  
- Capital allocation (heatmap visualization)  

### 🔹 **Project Budget Insights**
- Horizontal bar charts showing:
  - Budget by project name  
  - Budget by department  

### 🔹 **Status Filter**
- Filter entire dashboard by project status:
  - Upcoming  
  - Ongoing  
  - Completed
